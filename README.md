# A word - Crossword Puzzle Game

A complete React Native Expo crossword puzzle game called "A word" with a splash screen, game logic, settings, audio integration, and comprehensive documentation.

## Prerequisites

Before running the project, ensure you have the following installed:

| Requirement | Version | Installation |
|-------------|---------|--------------|
| Node.js | 18+ | https://nodejs.org |
| npm | 8+ | Included with Node.js |
| Android Studio | Latest | For Android builds |
| Xcode | Latest | For iOS builds (macOS only) |
| GitHub Desktop | Latest | https://desktop.github.com |

> **Note:** You do NOT need to install `expo-cli` globally. Modern Expo uses `npx expo` directly.

## Installation

### Step 1: Clone or Extract the Project

If you downloaded the zip file, extract it to a folder of your choice. The project folder should be named `Aword`.

### Step 2: Install Dependencies

Open a terminal and navigate to the project folder:

```bash
cd Aword
npm install
```

### Step 3: Add Audio Files

The audio files in the `assets/` folder are currently empty placeholders. You need to download real audio files and place them in the `assets/` directory:

| File | Description | Suggested Source |
|------|-------------|------------------|
| `intro_music.mp3` | Short intro/jingle (3-5 seconds) | Pixabay, Freesound |
| `background_music.mp3` | Looping background music | Pixabay, Freesound |
| `success.mp3` | Positive sound for correct answers | Pixabay, Freesound |
| `error.mp3` | Negative sound for wrong answers | Pixabay, Freesound |
| `applause.mp3` | Applause sound for winning | Pixabay, Freesound |
| `sad_tone.mp3` | Sad/melancholy sound for losing | Pixabay, Freesound |
| `cheer.mp3` | Cheering sound for winning | Pixabay, Freesound |
| `boo.mp3` | Booing sound for losing | Pixabay, Freesound |

You can find free audio files at:
- **Pixabay Sound Effects**: https://pixabay.com/sound-effects/
- **Freesound**: https://freesound.org/
- **Zapsplat**: https://www.zapsplat.com/

Run the helper script to see direct search links:
```bash
python3 assets/download_audio.py
```

## Running the Project

### Development Mode

To start the development server:

```bash
npx expo start
```

This will open the Expo Developer Tools in your browser. You can then:
- Scan the QR code with the **Expo Go** app on your phone (Android or iOS)
- Press `a` to open in Android emulator
- Press `i` to open in iOS simulator
- Press `w` to open in web browser

### Running on a Physical Device

1. Install **Expo Go** from the App Store (iOS) or Google Play Store (Android)
2. Make sure your phone and computer are on the same WiFi network
3. Scan the QR code displayed in the terminal or browser

## Building the App

### Prebuild (Generate Native Projects)

```bash
npx expo prebuild
```

This will generate the native Android and iOS project files including the auto-generated `.MainApplication`, `.MainActivity`, and `@style/AppTheme` referenced in `AndroidManifest.xml`.

### Build for Android

```bash
eas build --platform android --profile preview
```

### Build for iOS

```bash
eas build --platform ios --profile preview
```

> **Note:** The legacy `npx expo build:android` and `npx expo build:ios` commands have been deprecated. Use EAS Build instead.

## Features

### Splash Screen
- Orange background with the "A word" logo
- Animated intro with react-native-animatable (fadeInDown, fadeInUp, pulse, tada)
- Intro music plays automatically on launch
- Transitions to game screen after 3.5 seconds
- Displays "A word" and "by Ali Halim"

### Game Screen
- 5x5 crossword puzzle grid
- Real-time answer checking per cell
- Color feedback for correct answers (green border)
- Clues section for Across and Down
- Reset puzzle button
- Win/lose animations and sounds
- Proper async audio handling with error resilience

### Settings (Accessible via gear icon)
- **Dark Mode**: Toggle between light and dark themes
- **Vibration**: Enable/disable haptic feedback
- **Sound Effects**: Enable/disable game sounds
- **Background Music**: Enable/disable background music
- **Animations**: Enable/disable UI animations

All settings are persisted using AsyncStorage and loaded automatically on app launch.

### Audio System
- Background music loops during gameplay at 30% volume
- Individual sounds play for each action:
  - Correct answer: success sound + success haptic
  - Wrong answer: error sound + error haptic
  - Complete puzzle correctly: applause + cheer
  - Complete puzzle incorrectly: sad tone + boo
- All audio is loaded asynchronously with proper error handling
- Audio mode is configured for iOS silent mode playback

## GitHub Actions (CI/CD)

The project includes a pre-configured GitHub Actions workflow for automatic builds.

### Setup Steps

1. Open your repository on the **GitHub Website**
2. Click the **Actions** tab
3. You should see the "Expo Build CI/CD" workflow
4. Click on it to view the workflow file

### Required Secrets

To enable automatic builds, you need to add the following secret:

1. Go to **Settings** -> **Secrets and variables** -> **Actions**
2. Click **New repository secret**
3. Name: `EXPO_TOKEN`
4. Value: Your Expo EAS token (get it from `eas login`)

### How It Works

The workflow will:
- Trigger on every push to `main` or `master` branches (or manually via `workflow_dispatch`)
- Install all dependencies using `npm ci`
- Build the Android APK
- Build the iOS app
- Report success/failure in the Actions tab

### Manual Trigger

You can also trigger builds manually:
1. Go to the **Actions** tab
2. Click on the "Expo Build CI/CD" workflow
3. Click **Run workflow** -> **Run workflow**

## Troubleshooting

### Common Issues

| Issue | Solution |
|-------|----------|
| Metro bundler not starting | Delete `node_modules` and run `npm install` again |
| QR code not appearing | Run `npx expo start --clear` |
| Audio not playing | Ensure audio files are valid MP3 files in the assets folder |
| Build fails | Check that all dependencies are installed correctly |
| Icon not showing | Verify the icon file exists and AndroidManifest.xml is correct |
| Settings not saving | Check that AsyncStorage is installed properly |
| App crashes on start | Ensure `babel.config.js` exists in project root |
| EAS build profile not found | Ensure `eas.json` exists in project root |

### Debug Mode

To enable debug logging:

```bash
npx expo start --dev-client
```

### Clearing Cache

If you encounter persistent issues:

```bash
npx expo start --clear
```

Or:

```bash
rm -rf node_modules
npm install
npx expo start --clear
```
